# Task 4 – Fault-Tolerant Embedded Runtime System

## Objective
Develop a fault-tolerant embedded runtime system for detecting and handling battery system faults.

## Features
- Sensor disconnection detection
- Invalid reading detection
- Frozen ADC detection
- Relay mismatch detection
- Fault logging
- System state management
- Recovery handling

## System Modes
- NORMAL
- DEGRADED
- FAILSAFE
- SHUTDOWN

## Output
The system detects faults, changes the operating mode, records fault information, and provides recovery handling.
