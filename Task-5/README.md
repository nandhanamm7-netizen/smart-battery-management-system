# Task 5 – Intelligent Cloud Telemetry Architecture

## Objective
Implement cloud telemetry for the Smart BMS using the Blynk platform.

## Features
- Cloud-based battery monitoring
- Event-driven telemetry
- State-change detection
- Anomaly detection
- Voltage threshold monitoring
- WiFi reconnection handling
- Event synchronization after reconnection
- WiFi signal quality monitoring
- Non-blocking cloud communication

## Cloud Platform
- Blynk IoT
- ESP32
- Wokwi simulation

## Output
Battery and system information is transmitted to the Blynk cloud when important events, state changes, or anomalies occur.
