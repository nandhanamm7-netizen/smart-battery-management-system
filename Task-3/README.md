# Task 3 – Intelligent Embedded HMI & Diagnostic Interface

## Objective
Develop an embedded HMI for displaying battery system information and diagnostics.

## Features
- Display cell voltages
- Display pack voltage
- Display average cell voltage
- Display cell imbalance
- Display system status
- Display diagnostic information
- Rotate between different diagnostic screens

## Hardware / Simulation
- ESP32
- 16x2 I2C LCD
- Wokwi simulation

## Output
The LCD displays battery measurements and diagnostic information through rotating display screens.
