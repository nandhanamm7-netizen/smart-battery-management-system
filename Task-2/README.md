# Task 2 – Event-Driven Safety Protection Kernel

## Objective
Implement an event-driven safety protection controller for the battery management system.

## Features
- Monitor battery conditions
- Detect safety-related events
- Event-driven protection logic
- Non-blocking timing using millis()
- Recovery handling
- Relay control
- Buzzer indication
- Anti-relay chatter protection

## Output
The system responds to safety events and changes the protection state when required.
